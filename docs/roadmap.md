# Tennis Ecosystem App — Roadmap

## Product vision

"The social operating system for racket sports."

Не просто поиск партнёра или бронирование корта, а цифровая среда вокруг всей теннисной жизни пользователя.

**Центральный цикл:**
найти игрока → договориться → найти/забронировать корт → сыграть → зафиксировать результат → поделиться → найти следующую игру.

## Фазы продукта

### Фаза 1 — MVP: Основной цикл
Цель: игрок скачал → нашёл человека → договорился → сыграл → зафиксировал результат.

- Регистрация + базовый профиль (уровень, формат, расписание, фото)
- Поиск и просмотр игроков (карточки в стиле dating app)
- Структурированное предложение сыграть (дата / время / формат / район)
- Простой чат в рамках игры
- Фиксация результата матча
- Базовая история игр и статистика

### Фаза 2 — Корты и Open Games
Цель: замкнуть цикл «нашли человека → нашли корт → сыграли» внутри приложения.

- Каталог кортов (карта + список, фильтры, профиль клуба)
- Бронирование (сначала внешняя ссылка / ручное, потом API)
- Предложение кортов после мэтча с партнёром
- Split payment за корт
- Open Games — публичная игра, к которой может присоединиться другой игрок
- Лента открытых игр рядом

### Фаза 3 — Маркетплейс тренеров
Цель: новый тип аккаунта (тренер) + сценарий «хочу научиться / улучшить игру».

*Технически: расширение уже построенного профиля игрока — статус тренера + расписание + оплата.*

- Профили тренеров
- Бронирование индивидуального занятия
- Отзывы и рейтинг тренера
- Групповые тренировки с оплатой за место
- Подтверждение уровня игрока тренером

### Фаза 4 — Социальный слой
Цель: дать причину возвращаться после того, как постоянные партнёры уже найдены.

- Социальная лента (посты, фото, видео)
- Подписки / подписчики
- Публикация результата матча как пост (автоматическое предложение после игры)
- Достижения и бейджи
- Полноценный Tennis Journal (история, win rate, серии, любимые корты)
- Система репутации (reliability score, fair play)

### Фаза 5 — Соревнования
Цель: долгосрочная механика вовлечения для регулярных игроков.

- Мини-турниры между пользователями (сетка, результаты, победитель)
- Клубные турниры и события
- Лиги и ladders с дивизионами
- Round robin форматы
- Рейтинг на основе матчей (эволюция от self-reported к данным)

### Фаза 6 — Интеллект и автоматизация
Цель: перейти от «ищи сам» к «приложение само предлагает игру».

- Умный matchmaking (история матчей, уровень, расписание, расстояние)
- Проактивные рекомендации на главном экране
- Динамический рейтинг на основе результатов
- «You could play tomorrow» — автоматическое предложение в один тап

### Фаза 7 — B2B и масштабирование
Цель: дать клубам полноценный инструмент, выход в следующий город.

- CRM-витрина для клуба (расписание, аналитика, заполняемость)
- B2B дашборд для тренеров
- Расширение на другие ракеточные виды спорта
- Стратегия выхода в следующий город

## Технический стек

### Платформы
| Слой | Технология | Хостинг |
|------|-----------|---------|
| Web | Next.js | Vercel |
| Mobile | Expo (React Native) | EAS Build → App Store / Google Play |
| Backend API | Node.js + Hono | Railway |
| База данных | Supabase (PostgreSQL + PostGIS) | Supabase |
| Auth | Supabase Auth (email, Google, Apple, телефон) | Supabase |
| Realtime / Chat | Supabase Realtime | Supabase |
| Хранилище фото | Supabase Storage | Supabase |
| Хранилище видео | Cloudflare R2 | Cloudflare |
| Платежи | Stripe + Stripe Connect (split payment) | Stripe |
| Карты | Mapbox | Mapbox |
| Push-уведомления | Expo Push Notifications | Expo |

### Архитектура репозитория (monorepo)
```
tennis/
  packages/
    shared/       — API-клиент, TypeScript-типы, утилиты, константы
  apps/
    web/          — Next.js
    mobile/       — Expo / React Native
    backend/      — Node.js + Hono API
  docs/           — документация и артефакты
```

## Принципы фазирования

- **Связность раньше полноты** — лучше 4 функции, но связанные, чем 8 изолированных
- **Плотность раньше географии** — один город с высокой плотностью ценнее 10 тонких рынков
- **Монетизация следует за ценностью** — платежи с Фазы 2, когда есть что продавать
